How to use

Where videos go

A video is saved as

Chrome extensions can only save inside Chrome's download location. To put everything somewhere else, change "Location" in Chrome's download settings. Turn off "Ask where to save each file before downloading" there, or Chrome will ask every time.

Video quality

Useful for chat apps with an upload limit (Discord's free limit is 10 MB at the time of writing; check yours). Sizes are checked with the site before saving. If no version fits, the smallest is saved and you're told its size. Facebook sometimes offers only one size.

    When something goes wrong

    If a save fails while you're looking elsewhere (a Reddit merge that fails after you closed the tab, a download that breaks half-way), the toolbar icon shows a red count until you open ClipSnatcher or its history, where the problem is described.

    Copy helper (paste videos into Discord)

    Browsers can't put a video file on the clipboard by themselves. The optional helper is a small macOS script that puts a video file you saved with ClipSnatcher on the clipboard, the same as pressing ⌘C on it in Finder. It can also show that file in Finder. It accepts video files only.

    Browsers can't put a video file on the clipboard by themselves. The optional helper is a small Windows PowerShell script that puts a video file you saved with ClipSnatcher on the clipboard, the same as pressing Ctrl+C on it in File Explorer. It can also show that file in File Explorer. It accepts video files only.

    Your data
    
    
    ClipSnatcher has no servers and no analytics. History (titles, links, the video's address, file locations, small thumbnails) is stored only in this browser profile. Network requests go to the site hosting the post you chose, to fetch that video and its thumbnail. If a video is hosted somewhere else, you are asked before anything is downloaded from that host.
    
    
    
    
    
    
    
    A backup is one file with your whole history, notes, favourites and thumbnails. Restoring adds what's missing and leaves existing entries alone; the videos themselves are not part of it. Clearing history doesn't delete any video files.
