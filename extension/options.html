How to use

Where videos go

A video is saved as

Chrome extensions can only save inside Chrome's download location. To put everything somewhere else, change "Location" in Chrome's download settings. Turn off "Ask where to save each file before downloading" there, or Chrome will ask every time.

On the page

Keyboard: Alt+Shift+V opens ClipSnatcher. Change the shortcut

Copy helper (paste videos into Discord)

Browsers can't put a video file on the clipboard by themselves. The optional helper is a small macOS script that puts a video file you saved with ClipSnatcher on the clipboard, the same as pressing ⌘C on it in Finder. It can also show that file in Finder. It accepts video files only.

Checking…

To install, get the project from GitHub, then run this once in Terminal (no admin password needed). The command assumes the project is in ~/Projects/ClipSnatcher; change the path if you put it somewhere else.


      

      
Switching it on asks Chrome for permission to talk to the helper. ClipSnatcher only asks for this if you use the helper. Without it, the Copy button shows the file in Finder instead, where ⌘C then ⌘V in Discord does the same thing.

    

    

      
The one-click copy helper is available on macOS only. On this computer, use Show in folder on a saved video, copy the file there, and paste it into Discord.

    

  


  

    
Your data

    
ClipSnatcher has no servers and no analytics. History (titles, links, the video's address, file locations, small thumbnails) is stored only in this browser profile. Network requests go to the site hosting the post you chose, to fetch that video and its thumbnail. If a video is hosted somewhere else, you are asked before anything is downloaded from that host.

    

    

    
Clearing history doesn't delete any video files.
