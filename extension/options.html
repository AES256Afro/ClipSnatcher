Copy helper (paste videos into Discord)

Browsers can't put a video file on the clipboard by themselves. The optional helper is a small macOS script that does exactly one thing: put a file you saved with ClipStash on the clipboard, the same as pressing ⌘C on it in Finder. Then ⌘V in Discord attaches the video.

Checking…

To install, run this once in Terminal (no admin password needed), then click Check again:


    

    
Without the helper, the Copy button shows the file in Finder instead, where ⌘C then ⌘V in Discord does the same thing.

  


  

    
Your data

    
ClipStash has no servers and no analytics. History (titles, links, file locations, small thumbnails) is stored only in this browser profile. The only network requests go to the site hosting the post you chose, to fetch that video.

    

    

    
Clearing history doesn't delete any video files.
